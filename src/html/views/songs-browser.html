How Timestamp Saving Works

            
        

        

            
This saves the start point for one song in one specific service, so the next time someone clicks the recording it opens much closer to where the song begins.

            
    
                
  1. Open the recording for the past performance.
    2. 
                
  2. Pause where the song starts.
    3. 
                
  3. On YouTube, choose Copy video URL at current time.
    4. 
                
  4. Back here, click Save start time and paste the link.
    5. 
            

            
You can also type a plain timestamp like 2:13 or 17:36. Once saved, that song performance link will open at that time automatically.
